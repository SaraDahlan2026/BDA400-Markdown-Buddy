# Puppy Budget Project

## Overview
This project demonstrates basic R programming using a simple puppy budget example. It includes variables, calculations, and logical comparisons.

## Requirements
- R
- RStudio or Posit Cloud
- No additional packages required

## Installation
1. Open RStudio or Posit Cloud.
2. Open `Exercise1_Basic_R_Syntax.Rmd`.
3. Run the R code.

## Example Usage
The script uses:
- Number of puppies: 3
- Price per puppy: $300
- Budget: $1,000

The script calculates the total cost, checks whether the cost exceeds the budget, and determines the maximum number of puppies that can be purchased.
