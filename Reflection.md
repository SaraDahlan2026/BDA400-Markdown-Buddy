# Reflection Questions

## 1. How did AI help you create your project documentation?

ChatGPT helped me organize my README file and improve the Markdown formatting. It suggested useful sections and made my documentation clearer and easier to read.

## 2. What challenges did you face when using AI and Markdown?

One challenge was making sure the Markdown formatting was correct. I also needed to check the AI suggestions because they were not always perfect. I reviewed the content and made changes to improve it.

## 3. What did you learn about checking and improving AI-generated documentation?

I learned that AI is a helpful tool, but I should always review its work. I also learned how to use Markdown headings, lists, and code blocks to create clear documentation for my R project.
